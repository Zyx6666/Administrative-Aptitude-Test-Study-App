# 行测学习APP（个人离线版）

一个完全离线的安卓知识记忆 App：导入自己整理的 Markdown 内容，用「内容卡片」和「选择题」复习，按 **不会 / 模糊 / 会了** 分类管理，并按自定义间隔安排下次复习。

言语理解模块同时包含两套互相隔离的成语库：

- **我的错题本**：自己上传、从错题中总结的成语，原「知识库」入口
- **考频成语库**：按考频（真题出现次数）导入的成语，按频次分组、逐级解锁

其他五个模块保持原有「知识点 / 内容」用法不变。

当前 v1.6：
- v1.3 起，所有模块的导入与模板下载统一只使用 **Markdown（.md）**
- v1.4 起，导出统一为 **Markdown（.md）**，不再生成 CSV
- v1.5 新增「考频成语库」、错题语义文案与三列频次导入
- v1.6 考频库与错题本的同名成语学习状态双向同步

- 安装包：[行测学习APP-v1.6.apk](<行测学习APP-v1.6.apk>)
- 需求文档（历史版本）：[成语记忆 APP.md](<成语记忆 APP.md>)

## 一、模块架构

底层使用 `module_id` 隔离数据，每个模块有独立知识库、独立设置、独立分类和复习队列。六个模块全部启用，字段统一为「知识点 / 内容」。

| 模块 | module_id | 状态 | 页面文案 | 上传格式 |
|---|---|---|---|---|
| 时政 | current_affairs | 已启用 | 知识点 / 内容 | md |
| 常识 | common_sense | 已启用 | 知识点 / 内容 | md |
| 言语理解 | verbal | 已启用 | 知识点 / 内容（错题语义） | md |
| 数量关系 | quantity | 已启用 | 知识点 / 内容 | md |
| 判断推理 | judgment | 已启用 | 知识点 / 内容 | md |
| 资料分析 | data_analysis | 已启用 | 知识点 / 内容 | md |

- 首页顶部模块名可打开六个模块的切换列表，选择后整个 APP 切换到该模块。
- 每个模块的条目、分类、设置、复习时间完全独立，互不影响。
- **言语理解专属文案**：错题状态 / 我的错题本 / 全部错题 / 错题列表 / 搜索错题 / 刷内容卡片（错题）/ 做选择题练习（错题）/ 上传 MD 导入知识点（错题模块）。
- 其他五个模块仍显示：学习状态 / 我的知识库 / 全部知识点 / 知识列表 / 刷内容卡片 / 做选择题练习。

## 二、功能

### 知识库与导入（错题本）
- 只支持 `.md` 文件，其他格式会提示“目前只支持 .md 文件”
- 导入前预览前两行，并汇总新增 / 重复相同 / 重复不同 / 失败数量
- 以知识点文本去重；重复且内容不同时逐条选择“用旧 / 用新”
- 导入的新条目默认归入「不会」
- 言语理解入口文案为「上传 MD 导入知识点（错题模块）」，选择文件提示为「点击选择 .md 文件（只针对错题）」

### 考频成语库（仅言语理解）
- 首页独立入口「考频成语库」，与「我的错题本」数据互相隔离，但同名成语的学习状态双向同步（见下）
- 支持导入三列 Markdown：`成语 | 解释 | 频次`
- 按成语去重合并：已存在的成语只更新解释与频次，**保留已有学习状态**；重复导入结果幂等
- 首页顶部显示：共 N 个成语 · M 个频次组；可调整达标阈值
- 「学习状态（已解锁）」：不会 / 模糊 / 会了三张卡片，点击可按状态筛选已解锁成语
- 「全部成语」：共 N 个 · 已解锁 M 个，点击进入带搜索的成语列表（只展示已解锁频次组）
- 「考频分组」：每个频次一行，显示该组总数、不会 / 模糊 / 会了数量与状态（已达标 / 已解锁 / 未解锁）
- 点击已解锁分组可选择：内容卡片、选择题练习、查看成语列表
- 小组也能做选择题：干扰项从整个考频库抽取（全库需至少 4 条不同解释）

#### 与错题本的重叠同步
两个库分别导入，允许出现同名成语。重叠按成语名判定（忽略首尾空格），学习状态双向同步：

- **进入考频库时**（首页 / 频次组 / 全部成语列表）：把错题本中同名成语的状态同步到考频库
- **在考频库刷卡片或做选择题改状态时**：立即把新状态写回错题本同名成语
- 只同步「不会 / 模糊 / 会了」三态；两个库的解释与频次各自保留，互不覆盖
- 错题本中的「未学」在考频库按「不会」处理
- 导入考频 MD 时，重叠成语直接采用错题本当前状态；导入预览会提示重叠数量

#### 分组与解锁规则
1. 按频次从高到低分组，同一频次为一组（如 20 次组、19 次组……）
2. 最高频组始终可刷；只有前面的组全部达标，才解锁下一档
3. 达标条件（须同时满足）：
   - 组内没有「不会」（未学也计入未掌握）
   - 「模糊」数量 < 「会了」数量 × 阈值
4. 阈值默认 30%，可在考频库首页点击「达标线」调整（0～100）
   - 设为 0% 时，要求组内全部为「会了」
5. 组内可任意顺序刷，不强制按列表顺序
6. **回退即级联重锁**：已解锁组中若把成语改回「不会」，该组立即失效，所有更低频次的组一并锁回；解锁状态由当前数据实时推导，不单独存储

### 增删改查
- 「我的错题本 / 我的知识库」与三个分类列表都支持：
  - 点击查看详情、移动分类
  - 长按：修改知识点、修改内容、移动分类、删除
  - 右上角「+」添加知识点和内容
- 添加时可选择初始分类，默认「未学」
- 修改知识点时检查重复，重复会阻止保存
- 删除有二次确认，删除后不再进入复习队列
- 考频库列表为只读查看，学习状态通过刷题改变

### 内容卡片
- 正面只显示知识点，内容默认遮住
- 「看内容」后内容在卡片内上下居中显示
- 三个竖排描边按钮：不会（红）/ 模糊（橙）/ 会了（绿）
- 支持「我认识，不看答案」和「跳过」
- 考频库的卡片标题显示为「20 次组 · 内容卡片」

### 选择题
- 1 个正确选项 + 3 个随机干扰项，A-D 随机
- 答错显示正确答案与完整内容
- 只有“原状态为会了且答错”才弹出不会 / 模糊 / 会了三按钮
- 其余情况分类不变，只更新复习时间
- 考频库的选择题标题显示为「20 次组 · 选择题」

### 刷题数量
- 「+ / -」调整
- 数字区域可直接用输入法输入
- 范围 1～999；为空或非法，失焦后恢复默认值
- 超过实际条目数时按实际数量开始，并提示
- 考频库按当前频次组的实际数量刷题

### 列表与设置
- 三个分类列表独立搜索、排序、专项复习、导出
- 设置按模块隔离：复习间隔、抽取比例、每次数量
- 导出当前模块或当前列表为 UTF-8 Markdown 表格（`.md`），三个分类列表与「我的错题本 / 我的知识库」一致
- 清除数据仅清除当前模块的错题本条目，考频库数据独立保留，需二次确认

## 三、Markdown 导入格式

### 1. 错题本 / 普通知识库：两列

统一使用两列：`知识点`、`内容`。支持两种写法。

#### 表格写法

```markdown
| 知识点 | 内容 |
| --- | --- |
| 基期量 | $基期量=\frac{现期量}{1+增长率}$ |
| 增长率 | $增长率=\frac{增长量}{基期量}\times100\%$ |
```

#### 标题作为知识点、下面段落作为内容

```markdown
## 充分条件
若 $A \Rightarrow B$，则 A 是 B 的充分条件。

## 必要条件
若 $A \Rightarrow B$，则 B 是 A 的必要条件。
```

解析规则：
- `**加粗**`、`__加粗__` 会去掉符号，按普通文本显示
- 标题、列表、引用、链接、代码标记会转成普通文本
- 公式定界符统一转换：`$...$` / `\(...\)` / `\[...\]` / `$$...$$` 均可
- 公式使用 JLatexMath 在本机离线渲染，不依赖网络

### 2. 考频成语库：三列

```markdown
| 成语 | 解释 | 频次 |
| --- | --- | --- |
| 差强人意 | 大体上还能使人满意，常被误用为“不满意”。 | 20 |
| 不刊之论 | 指不能改动或不可磨灭的言论。 | 19 |
```

解析规则：
- 表头可识别：成语 / 词条 / 知识点 / 名称；解释 / 释义 / 含义 / 内容 / 说明；频次 / 考频 / 次数 / 频率
- 没有表头时，按固定三列处理
- 频次列可写 `20` 或 `20 次`，取其中的数字；小于等于 0 或非数字视为无效行
- 同一文件内成语重复：解释取最新值，频次取最大值
- 导入时与库内已有成语按名称去重合并，学习状态不重置

## 五、数据模型（v3）

```sql
entries(
  id, module_id, source_type, term, content, frequency, category,
  unknown_count, fuzzy_count, known_count,
  choice_correct_count, choice_wrong_count,
  last_choice_result, last_choice_at, known_without_answer,
  last_review_at, next_review_at, created_at, updated_at
)
UNIQUE INDEX (module_id, source_type, term)
```

- `source_type`：`self`（我的错题本）/ `freq`（考频成语库）
- `frequency`：考频次数，普通库为 0
- `category`：`unlearned` / `unknown` / `fuzzy` / `known`
- 设置表使用 `模块ID:键名` 前缀隔离；考频阈值为 `freq_threshold_percent`，默认 30
- 数据库版本 3，升级时自动补齐 `source_type` 与 `frequency`，重建唯一索引
- 从 v1 升级时自动把 `idioms` 表迁移到 `entries`，`module_id='verbal'`，原数据不丢失
- 「未学」只出现在错题本 / 知识库，不进入三个分类列表；全部库复习时按“不会”池参与抽取
- 考频库的解锁状态不落库，由频次分组 + 当前学习状态实时计算

## 八、已知限制

- 导入与导出只支持 `.md`，不再支持 xlsx / xls / csv。
- 导出的 Markdown 包含学习统计列，但重新导入只恢复知识点和内容，学习记录不会恢复。
- 公式渲染基于 LaTeX（JLatexMath）；OMML、MathType 图片公式不支持。
- 选择题需要至少 4 条且内容互不相同；考频库按全库干扰项判断。
- 修改复习间隔只影响之后的点击，不会重算已排好的时间。
- 「未学」条目不会出现在三个分类列表里，可在「我的错题本 / 我的知识库」或全部库复习中处理。
- 考频库锁定分组不可刷题、不可查看内容；只有已解锁分组计入「学习状态（已解锁）」与「全部成语」列表。
- 考频阈值口径为：模糊数量 < 会了数量 × 阈值；0% 表示组内不允许模糊。
